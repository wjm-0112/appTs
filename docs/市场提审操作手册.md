# 安卓市场提审操作手册（分市场实战）

> 配套工具：appTs 提审工作台（知识库内亦有同源 6 篇《XX 提审方案》可直接阅读与复制）。
> 后台界面可能调整，以下入口/字段供参考；均以各市场官方最新要求为准。核实于 2026-09。

## 0. 跨市场通用前提（先于任何提审动作）
1. **三处名称一致**：APP 名 = 软著名 = 工信部备案名；著作权人 = 营业执照主体 = 开发者账号主体；
2. **APP 备案**完成并取得备案号（2023 起强制，市场联网校验）；
3. **软著三选一**下证；未下证可加急（10–15 天）或按市场规则用替代材料（仅应用宝支持后补）；
4. 包体：Release 正式签名 + 64 位；隐私政策独立 URL + 首启弹窗（同意/拒绝双选项）；
5. 隐私弹窗同意前 SDK 零采集；敏感权限使用时申请、拒绝不退出、提供注销（≤15 日）。

## 1. 六市场速查表

| 市场 | 注册入口 | 账号/费用 | 软著 | 首次审核 | 特别强项 |
|---|---|---|---|---|---|

## 2. 各市场提审关键路径（速记）
- **华为**：注册实名 → AGC 新建应用 → 填信息/素材/隐私声明 → 版权信息传软著+行业资质 → 版本页填备案并**校验证件号** → 上传 64 位包 → 备注测试账号 → 提交。
- **小米**：注册+打款验证 → 创建应用（包名不可改）→ 完美图标+无水印截图 → 传软著/备案/行业资质/测试报告 → 传包（>50M 用大文件助手）→ 备注测试账号 → 提交。
- **OPPO**：认证 → 创建应用（包名不可改）→ 一句话简介 ≤13 字无标点 → 权限逐条+功能截图 → 软著/备案 → （高敏类目测试报告）→ 传包 → 提交。
- **vivo**：认证 → 创建应用 → 介绍/图标/截图（首屏隐私合规）→ 软著（名一致）/备案 → AI 类加标识 → 传包（稳定优先）→ 提交。
- **荣耀**：认证 → 创建应用（名称 ≤15 汉字、无泛化词）→ 素材规范严格 → 软著/备案 → 传 64 位正式包 → 备注测试账号 → 提交。
- **应用宝**：QQ 登录注册 → 新建移动应用 → 资质证明（软著或替代材料 + 承诺函 + ICP 材料）→ 传 32/64 位包 → 短信验证 → 提交。

## 3. 多市场并行排期建议（六市场同包同一主体）
```
第 1–2 周  软著（加急）+ 域名 ICP 备案（并行）
第 2–4 周  工信部 APP 备案（接 ICP 完成后提交）
第 3 周    六市场开发者账号注册/认证（并行，1–3 天/家）
第 4 周    素材统一准备 + 隐私政策页上线 + 打包自检
第 4–5 周  首发：应用宝 / vivo（审核门槛较低，先跑通共性）
第 5–6 周  同步：小米 / OPPO / 荣耀 / 华为（最严口径已按华为整改）
上线后     30 日内公安联网备案；各市场版本同步迭代（1–3 天复审）
```

## 5. 各市场易踩坑（对照自查）
- 华为：备案证件号「5/S、1/I、0/O」抄错 → 校验失败；名称与包内不一致。
- 小米：截图带竞品机型外框；图标非圆角适配；高敏类目漏第三方报告。
- OPPO：权限说明缺场景/无功能截图；第三方报告版本号与提审包不一致；**欺骗上架会冻结账号**。
- vivo：软著名与应用名不一致；AI 生成无标识或提供去水印。
- 荣耀：32 位包被拒；应用名泛化/含特殊字符；单内容聚合应用（单一壁纸/攻略）被拒。
- 应用宝：软著缺失且无替代材料；承诺函用错模板（金融/购物/医疗/网赚有专用版）；描述含其它商店名。

## 6. 被驳回后的标准动作
1. 在工具 App 详情「市场提审」把该市场置为**被驳回并填原因**；
2. 对照本手册第 5 节与知识库《高频驳回 TOP6》定位根因；
3. 整改后在「备注」记录方案 → 重新提交（多数 1–2 天复审）；
4. 华为/小米口径最严：以它们的要求统一整改，可避免其它市场二次驳回。
